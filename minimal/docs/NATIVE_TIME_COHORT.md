# X4 0.1.8 native-time cohort

This explicit `--sleep --desk-clock --sparse-clock` product composes the native
UTC clock, selected Reader/IANA timezone, retained minute wake and tagged alarm
API2 clients as one admitted store. It keeps the paired 16 MiB flash layout.
The ordinary migration source and delivered0.1.6/0.1.7 images are unchanged.

All sixteen applications require `alarm.service@2`. The exact provider0.4.4
uses readonly `platform.realtime` and the nine listed UTC/preference keys; it
does not read an external RTC. Only Clock and Settings have realtime control.
Other applications have the readonly reader. Their per-app receipts bind the
compiled ELF, source checkpoint and four canonical SDK headers. The source pin
used to compile an SDK is recorded separately from the selected native firmware.
The complete store must pass the actual Runtime/ELF admission gate.

Clock cold/foreground entry explicitly promotes the complete admitted graph.
Valid retained timer entry uses demand activation and keeps the alarm closure.
The selected graph's ordinary-provider closure is board power, frontlight,
panel, X4 power and alarm service; native capabilities do not add ordinary
provider images. This is a dependency-topology count, not a measured hardware
startup time or battery-current claim. Unknown/partial promotion cannot return
to the sparse path. Light wake consumes the checked API2 alarm ticket once.

Settings exposes only supported manual Light and Deep modes, six faces, the
Reader timezone catalog, language selection and Clock/Settings flip preference.
Missing timezone preferences use the checked virtual UTC default. A timezone
change adjusts local presentation and future local schedules; it does not
silently rewrite RTC contents or historical records. Set the intended timezone,
then explicitly save time if the retained RTC's interpretation is unknown.
Native alarm/countdown/Points and Stopwatch records use separate UTC keys.
Timecard retains its civil ledger and existing worked-wall-time semantics.

Reader automatic idle entry and general app-wide language/flip adoption remain
separate work. Serial Monitor, X4 OTA/App Store backend integration and physical
sleep/rail/current qualification are not established by this candidate. The
requested full-image flash overwrites firmware, partitions, NVS and app data;
it is a UC8279 first-install test image, not a data-preserving update.

The source includes local integration checkpoints whose GitHub publication is
still under review. A successful target build and private test artifact do not
establish that these checkpoints are published, merged or hardware-qualified.
